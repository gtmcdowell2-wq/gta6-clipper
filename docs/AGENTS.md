# The agent network: 120 agents

Generated from the code (`python run_pipeline.py agents` prints the same list). Each agent has one job, a schedule, a pause switch, an activity log and a backup plan for when its normal method fails. Agents in the same *lane* take turns on one thread; separate lanes run in parallel, and the Watchdog restarts any lane that stops.

Per-streamer Scouts are created from `sources.yaml`, so adding a streamer adds a Scout.

## Judges panel (10)

Critiques, scores reach and decides what is ready for you.

| Agent | Job | Backup plan | Lane |
|---|---|---|---|
| **Hook Critic** | A second, independent Claude read of each finished clip as a cold viewer: does the opening stop the scroll, does it make sense without context, is the title honest? Suggests a better title and hook. | Without Claude (no key, outage or budget spent) it scores the hook and title with fixed rules instead and says so on the card. | `llm` |
| **Visual Judge** | Shows Claude four frames of the finished clip: is it gameplay or a story cutscene, is the opening graphic, is the facecam framed well, is any text unreadable, and which frame makes the best cover. | Without Claude it records 'skipped' and leaves the picture checks to the Cutscene Detector, Facecam and Thumbnail inspectors. | `llm` |
| **Signal Scorer** | Scores how strong the original moment was: where its audio and chat spike ranks among every candidate from the same stream. | If the measurement it needs is missing it records 'skipped' instead of guessing, and the Gatekeeper treats that as a reason for a human look. | `judges` |
| **Archetype Scorer** | Scores the clip's type (freakout, comedy, discovery, hot take, chaos/skill) by what has been earning views on your accounts, starting from launch-week priors. | If the measurement it needs is missing it records 'skipped' instead of guessing, and the Gatekeeper treats that as a reason for a human look. | `judges` |
| **Freshness Scorer** | Scores how recent the moment is. In launch week a clip loses most of its value within a day, so fresh moments go to the front. | If the measurement it needs is missing it records 'skipped' instead of guessing, and the Gatekeeper treats that as a reason for a human look. | `judges` |
| **Length Scorer** | Scores length against what finishes best: 18-45 seconds is the sweet spot across TikTok, Reels and Shorts. | If the measurement it needs is missing it records 'skipped' instead of guessing, and the Gatekeeper treats that as a reason for a human look. | `judges` |
| **Trend Scorer** | Scores how well the title and caption match what's trending in gaming right now (terms collected by the Trend Watcher). | If the measurement it needs is missing it records 'skipped' instead of guessing, and the Gatekeeper treats that as a reason for a human look. | `judges` |
| **Streamer Pull Scorer** | Scores the streamer's pull on your accounts: average views of their past clips compared with your overall average. | If the measurement it needs is missing it records 'skipped' instead of guessing, and the Gatekeeper treats that as a reason for a human look. | `judges` |
| **Reach Forecaster** | Combines the six scorers, the Moment Picker's own scores and the Hook Critic into one 0-100 reach score. | **Gatekeeper** | Waits for every inspector and judge, then writes one recommendation on the review card: ready, needs a look, reject, or blocked (source not permitted). It only approves on its own if you turn on auto_approve_threshold. | If some checker is paused or stuck for 30 minutes it decides with the verdicts it has and lists what was missing. | `judges` |

## Operations crew (16)

Keeps the machine healthy, backed up, updated and talking to you.

| Agent | Job | Backup plan | Lane |
|---|---|---|---|
| **Watchdog** | Checks every lane's heartbeat every 20 seconds: restarts any lane whose thread has died, and flags an agent that has been running far longer than it should. | The Watchdog's own lane is restarted by a guardian thread inside the orchestrator. | `watchdog` |
| **Supervisor** | Puts work that got stuck mid-step back in the queue (renders, downloads, uploads), retries failed downloads and renders once, and raises an alert when an agent keeps failing. | After one automatic retry it stops and asks for a human, so a broken input can't loop forever. | `ops` |
| **Janitor** | Deletes raw VOD files once every clip from them has been reviewed and the retention period has passed, and removes rejected clip files after a week. | When the Disk Forecaster sees the drive filling fast, it halves the retention period until there's room again. | `ops` |
| **Archivist** | Backs up the database every 6 hours (a consistent snapshot, safe while everything runs) plus your config and sources files, keeping the last 2 weeks. | If a backup fails it keeps the previous ones untouched and raises an alert; the Backup Verifier checks every new copy. | `ops` |
| **Backup Verifier** | Opens the newest backup on its own, runs SQLite's integrity check and compares row counts with the live database, so a backup is known to restore before you ever need it. | A failed check raises an error alert and asks the Archivist for a fresh copy. | `ops` |
| **Health Monitor** | Measures the machine every 5 minutes: free disk, database size, memory and, with an NVIDIA card, GPU load, memory and temperature. | Readings it can't take on this computer are left blank rather than guessed. | `ops` |
